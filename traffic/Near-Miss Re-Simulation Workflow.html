Near-Miss Re-Simulation Workflow
Concept workflow · Draft for discussion

Safety design testing in the digital twin

Test the safety fix before it's built

Measure near-misses at today's intersection from camera video. Rebuild those incidents in a calibrated Vissim model. Then run the same traffic through a set of design alternatives, score each one with the same video analytics, and compare them side by side in the UE5 twin.

The question each project answersWhich alternative reduces conflicts the most, and where do the remaining ones move?

Who does what, phase by phase

Each lane is one discipline. Labeled arrows are handoffs between teams.

Agree on five rules at kickoff

These keep every alternative's numbers comparable. Each one is cheap to set up front and expensive to fix later.

  • One coordinate system

    Roadway design's survey control. Video trajectories, CAD, the splat capture, the Vissim network and the FZP output all register to it.

  • One conflict pipeline

    Field video and rendered video go through the same analytics, via the API, with TTC and PET thresholds fixed at kickoff.

  • Calibrate before predicting

    Match counts, speeds and the observed heatmap, and replay the incidents in the twin, before any alternative runs.

  • Existing is Alternative 0

    Render the calibrated existing model and send it through the API too, so today's conditions are measured the same way as every option.

  • Report relative change

    Show conflict reduction per alternative next to HSM crash modification factors. It shows direction and size of change, not a crash guarantee.

Prove it with a backcast

One pilot site gives every discipline a reason to trust the method, and gives us the proof slide.

  1. Pick an intersection where a safety fix is already built and video exists from before and after construction.
  2. Run all five phases using only the before video, with the as-built design as the alternative.
  3. In the twin, compare the predicted conflict heatmap with the one the API measures from the real after video.
  4. Use the gap to tune the method, then repeat on each new post-construction dataset.
